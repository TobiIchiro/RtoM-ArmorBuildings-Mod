This is a set of two mods for the game The Lord of the Rings: Retutn to Moria that can be used simultaneously

Custom Armors

This mod adds every DLC Packs released up-to-date recipes. Also, adds Lord of Moria armor set and Origin Set.

Custom Constructions

This mod restores some buildings that were removed in game verison v1.2 due to the inestability of the constction system. In adition, it adds more than 40 new Constructions to the game.
