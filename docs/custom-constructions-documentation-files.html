Unpacking

  1. Download Retoc and extract .zip file on working directory i.e WorkingDirectory/Retoc

  2. Open a terminal where Retoc.exe is located

  3. Type this command in terminal:

    .\retoc.exe to-legacy --version UE4_27 [path to Moria-WindowsNoEditor] [path to unpack]

    Example:

    .\retoc.exe to-legacy --version UE4_27 E:\Juegos\Epic\ReturnToMoria\Moria\Content\Paks F:\RtoM\retocExports

Install mod

  1. Copy directory where MyMod_P.utocwas created

  2. Go where your games instalation packs are located and paste the directory inside ~mods (if ~mods directory doesn't exist, create it)

    Example:

    E:\Juegos\Epic\ReturnToMoria\Moria\Content\Paks\~mods
